# Trust Design Navi v7.5 — Value Proposition Canvas

## 概要

このドキュメントは、Trust Design Navi（TDN）プロジェクトのバリュープロポジションキャンバス（VPC）v7.5 を記録するものである。v7 から v7.5 への主な変更点は、裏テーマとして「家族任せ・性別役割任せをやめる」「2040年問題（単身世帯増）への備え」「COTEN型の構造理解」「世代間負担の引き受け」「賢く繋がる実践者像」を統合した点にある。

判断軸の土台は [MANIFESTO.md](MANIFESTO.md) を参照。

---

## 底流テーマ（Undercurrent themes）

| テーマ | 内容 | 設計方針 |
|---|---|---|
| 家族任せ・性別任せをやめる | 家族あり前提の終活サービスへの問い直し | 前面に出さず、コンテンツの底流として効かせる |
| 2040年問題 | 単身世帯約4割になる社会への備え | 数字で軽く触れ、煽らない |
| COTEN型の構造理解 | 個人の悩みを社会構造に接続して理解する | 歴史・社会の文脈解説を「学ぶ」レイヤーに織り込む |
| 世代間負担の引き受け | 受益側として相応の負担増を冷静に引き受ける | 「大人の選択」として、説教調にならず |
| 賢く繋がる実践者 | 専門家・支援サービスを主体的に活用する | 受け身でなく対等な関係を志向 |

## コアペルソナ

> **「家族の枠に縛られず、自立期に主体的に備えたい40-50代」**

### サブセグメント

- **A. 親サポート世代**：介護・終活サポートで奔走、自分の備えも始めた人
- **B. 単身／子なし世帯**：「家族に頼れない／頼りたくない」前提で備える人（創業者自身は子なし夫婦。いずれどちらかが単身になる前提で備える当事者）
- **C. ケアを背負う／避けたい女性**：介護離職リスクと性別役割への違和感を持つ人

横串：「家族任せ・性別役割任せをやめる」「賢く繋がる実践者でありたい」

## カスタマープロファイル

### Customer jobs

- 親の終活サポートで家族情報・資産・デジタル足跡を整理する
- その経験を自分の備えに転用する
- デジタル/SNS/クリプトという見落とし領域を扱う
- 家族の有無に関わらず備えを自分でデザインする
- 性別役割で背負わされたくない／背負わせたくない
- 不安を社会構造に接続して理解したい
- 専門家・支援サービスを主体的に活用したい

### Pains

- 既存終活サービスはほぼ全て「家族あり・配偶者あり・子あり」前提
- 「女性だから（嫁だから・娘だから）当然」の無言圧、介護離職リスク
- 単身世帯向け代替支援（任意後見・死後事務委任・見守り・デジタル代替）の情報が散らばっている
- デジタル/SNS/クリプト領域がスッポリ抜けている
- 重い話を家族と切り出すきっかけがない
- 個人の悩みを社会構造に接続して語る場所がない
- 専門家との繋がり方が分からず受動的になりがち

### Gains

- 家族の有無に関わらない「個」としての備え
- 家族以外の選択肢を知って選べる
- 同じ志の実践者と繋がれる
- 「自分のせい」からの解放、自責が緩む
- 小さく規範を動かしている実感
- 専門家と対等に繋がれる
- 世代間負担を冷静に引き受けるという成熟した立ち位置

## バリュープロポジション

### Products and services（3レイヤー構造）

#### 学ぶ（軽く始める）
- 10テーマガイド
- デジタル/SNS/クリプト 専用モジュール（厚く）
- 「家族に頼らない備え」モジュール（任意後見・死後事務委任・見守り・デジタル代替）
- 歴史・社会構造解説コンテンツ（COTEN型）
  - 女性の介護負担の歴史的経緯
  - 2040年問題と単身世帯化の構造
  - 「家族モデル」は歴史的構築物である
- 創業者の実践Newsletter／ブログ
- 多様なケーススタディ（親サポート／おひとり様／子なし夫婦／共働き介護）

#### 決める（準備する）★差別化の主戦場
- 現在地診断（家族構成・性別役割の前提を分岐で扱う）
- デジタル遺品リスト作成ツール
- SNS死後対応フロー（X/Meta/Google等の死後対応URL集約＋意思表示テンプレ）
- クリプト/シードフレーズ託しガイド（分散保管・遺族への伝え方・Multi-sig活用）
- おひとり様向け：任意後見・死後事務委任契約 入門＋テンプレ
- 介護離職リスク回避ツール（ケアマネ活用／レスパイト／地域包括ケアの使い倒し方／配偶者間のケア分担シート）
- 専門家連携前のチェックリスト

#### 託す（共有する）
- 関係性マップ（家族＋友人＋士業＋地域＋サービス）
- 安心デザインカード（1枚で家族・友人・士業・行政すべてに共有可）
- 共有リンク・PDF出力

#### 外側（Phase 2）
- 実践者Slackコミュニティ（多様な立場を明示的に尊重するガイドライン）
- 月次オンライン勉強会（構造を学ぶ回／実践を共有する回の両輪）

### Pain relievers

- 「親サポート」を入口にし、終活の重さを下げる
- 家族構成・性別役割の前提を診断で分岐し、押し付け感を排除
- デジタル領域を一気通貫で扱い、既存サービスの抜けを埋める
- 構造解説で「自分のせい」感から解放する
- 関係性マップで家族以外の繋がりを可視化

### Gain creators

- 家族以外の選択肢を提示（任意後見・死後事務委任・地域・デジタル）
- 親 → 自分への2段階学習構造
- 同じ問題意識の実践者ネットワーク（孤独解消）
- 専門家連携前の「整理」を自分でできる
- ボトムアップで規範を動かす運動への参加実感
- COTENとの役割分担：「下から」の実践

## 既存終活サービスとの差別化マトリクス

| | 一般的な終活サービス | TDN v7.5 |
|---|---|---|
| 顧客像 | 高齢者本人＋家族 | 自立期＋家族の枠を問わない |
| 家族観 | 家族あり前提 | 家族の有無を問わない |
| ジェンダー | 暗黙の女性負担 | ジェンダー視点で再設計 |
| 領域 | 相続・介護中心、紙ベース | デジタル/SNS/クリプト厚め、Web |
| 提供価値 | 個人課題の解決 | 個人課題＋社会構造への接続 |
| 形態 | 単発相談／本／ノート | 学び＋ツール＋コミュニティの三位一体 |
| 専門家関係 | 専門家に丸投げ | 専門家と対等に繋がる支援 |
