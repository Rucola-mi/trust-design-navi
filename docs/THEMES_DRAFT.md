# Trust Design Navi v7.5 — 6テーマ コンテンツ草稿（Task 1, v3）

このドキュメントは、Phase 1 Task 1 の成果物。6テーマそれぞれの `name` / `desc` / `priorityHint` / `whatToKnow` / `whereToLearn` / `beforeTalking` の草稿に加え、**親をサポートする視点（別建てセクション）**を記載する。

**v3 での変更**：
- テーマ4 `whatToKnow` の冒頭を圧縮（任意後見・死後事務委任の定義を省略、終身サポート事業者の話に直行）
- 「業界には悪質業者によるトラブルも多く」→「**現時点では参入障壁が低いことで、悪質業者によるトラブルの増加が懸念されており**」（前向きトーン）
- 全終協を「**日本初の業界団体**」とニュートラルに紹介
- `forParentSupport` を各テーマから外し、**別建てセクション**（`PARENT_SUPPORT_HINTS`）として独立

底流テーマ（マニフェスト準拠）の織り込みは v2 と同じ。

## テーマ4：家族以外の支援 ★差別化の刃

旧6「身元保証」＋旧8「後見人」＋新12要素「任意後見・死後事務委任・高齢者等終身サポート事業」を統合。**底流テーマが最も色濃く出るテーマ**。

| フィールド | 内容 |
|---|---|
| `id` | 4 |
| `name` | 家族以外の支援 |
| `desc` | 入院・施設入所時の身元保証、判断力が衰えた時の支援、死後の事務など、家族以外も含めた支援の備えについて、今の状態に近いものを選んでください。 |
| `priorityHint` | 家族の有無に関わらず、自分の意思を支えてくれる仕組みがあります。任意後見・死後事務委任・終身サポート事業など、選択肢を知ることから。 |
| `whatToKnow` | 任意後見契約、死後事務委任契約などをワンストップで引き受ける**「高齢者等終身サポート事業者」**が、特に子のいない世帯や単身世帯にとって現実的な選択肢になりつつあります。現時点では参入障壁が低いことで、悪質業者によるトラブルの増加が懸念されており、2024年に国（法務省）がガイドラインを示し、2025年8月には日本初の業界団体「全国高齢者等終身サポート事業者協会（全終協）」が設立されるなど、健全化の動きがいま本格化しています。 |
| `whereToLearn` | 公証役場の任意後見契約案内／法務省の高齢者等終身サポート事業者ガイドライン（2024年）／日本初の業界団体「全国高齢者等終身サポート事業者協会（全終協）」の優良事業者認定・通報窓口（[zenshukyo.org](https://www.zenshukyo.org/)）／日本弁護士連合会の任意後見・死後事務相談／お住まいの社会福祉協議会／消費生活センター。 |
| `beforeTalking` | 家族・親族・友人・専門家・サービス事業者、それぞれを「頼める／頼めない」「頼みたい／頼みたくない」で整理してみる。終身サポート事業者を選ぶ際は、**料金体系の透明性、第三者監督の有無、契約解除のしやすさ**が見極めポイント。なお、利用者からの財産寄付（遺贈）を受け付けている事業者は、支援者が受益者を兼ねる構造的な利益相反になりえます。善意の事業者であっても、この構造があることは認識した上で選びましょう。 |

**底流の織り込み**：「家族任せをやめる」のど真ん中／単身世帯増（2040年問題）への直接的な備え／専門家・サービスと賢く繋がる／**ドライに利益相反を指摘**してユーザーに考える材料を渡す。

## テーマ5：死後の手続きと相続

旧9「死後の事務」＋旧10「相続・遺言・寄付」を統合。終身サポート業者の利益相反論点も再掲。

| フィールド | 内容 |
|---|---|
| `id` | 5 |
| `name` | 死後の手続きと相続 |
| `desc` | 葬儀・お墓・死後の各種手続き、そして財産の引き継ぎや遺言・寄付について、今の状態に近いものを選んでください。 |
| `priorityHint` | 死後の手続きは想像以上に多いです。引き継ぎたい人・残したい想いを、自分の言葉で残せる方法があります。 |
| `whatToKnow` | 死後には葬儀・火葬・年金停止・健康保険返却・公共料金解約・各種SNS停止など多くの事務があります。遺言書がない場合、財産は法定相続人に法定割合で分けられます。**遺言（自筆／公正証書）**で希望を反映でき、相続人以外への遺贈や、社会への**寄付（遺贈寄付）**も可能です。家族に手続きを背負わせない方法として**死後事務委任契約**もあり、終身サポート事業者がこれを引き受けるケースが増えています（テーマ4参照）。 |
| `whereToLearn` | 法務局の自筆証書遺言保管制度（手数料3,900円で安全に保管）／公証役場の公正証書遺言相談／法テラスの無料法律相談／日本承継寄付協会など寄付の専門窓口／自治体の「おくやみハンドブック」。 |
| `beforeTalking` | 葬儀の形・お墓の方向性・連絡してほしい人。「誰に何を残したいか」「残さないものは何か」「社会に還したい想いはあるか」。なお、死後事務を引き受ける事業者が遺贈寄付の受取先を兼ねる場合は、支援者と受益者が同一になる利益相反構造があります。寄付の意思があるなら、寄付先と死後事務の依頼先は分けて考えるのが原則です。 |

**底流の織り込み**：遺贈寄付＝社会への還元という視点（世代間負担の引き受けに繋がる）／家族に手続きを背負わせない選択肢／**利益相反の構造を再度ドライに指摘**（テーマ4と重ねて意識を促す）。

## 親をサポートする視点（別建てセクション）

各テーマと対をなす、**親世代の終活サポート視点のヒント集**。
データ構造は `THEMES` とは独立した `PARENT_SUPPORT_HINTS` オブジェクトとする。

```javascript
const PARENT_SUPPORT_HINTS = {
  1: "親のACPは、元気なうちに「もしもの時の希望」を3つだけでも聞いておく。意思を文字に残すきっかけは本人からは出にくいので、こちらから機会を作る。",
  2: "親の住まいや見守りは、まず地域包括支援センターに親本人と一緒に行ってみる。要介護認定の前から相談できる。早めに「顔の見える関係」を作っておくと、緊急時に動きやすい。",
  3: "親の資産は、いきなり全体を聞き出そうとしない。「どこの銀行を使っているか」「主治医は誰か」など、ありかの情報から少しずつ。金額の話は最後で十分。",
  4: "親が一人暮らしや高齢夫婦のみ世帯なら、入院・施設入所時の身元保証をどうするか、判断力があるうちに一緒に考える。任意後見契約は元気なうちにしか結べない。終身サポート事業者の検討も、悪質業者リスクを理解した上で、複数を比較する。",
  5: "親が遺言書を書いていないことが大半。重い話に聞こえないように、「法務局で安全に保管できる制度ができたよ」のような中立的な情報共有から始める。葬儀の希望も、形式ばらず「あなたは静かなお別れがいい？にぎやかなのがいい？」程度から。",
  6: "親のスマホ・PCのロック解除方法、利用しているサービス、サブスクは、本人が把握できなくなる前にメモを残してもらう。デジタル遺品整理は本人不在では極めて困難。「スマホの暗証番号、メモしてある？」の一言から始められる。"
};
```

### 表示方針

- 表示位置：診断結果画面の独立ブロック「親をサポートする時のヒント」として一括表示（または優先テーマに対応するヒントだけハイライト）
- 表示条件：Phase 1 ではデフォルト表示。Phase 2 以降で Task 10（診断前提ヒアリング）と連動し、「親サポート世代」と回答したユーザーにのみ表示
- AIナビゲーター結果カードへの組み込みはしない（情報過多を避ける）
