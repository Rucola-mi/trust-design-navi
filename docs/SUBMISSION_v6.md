## プロダクト名

**Trust Design Navi（TDN）** — これからの安心は、自分でデザインする。

## ひとことで

家族の枠に縛られず、自立期（40–50代）に主体的に「終活」を備えるための、学ぶ・決める・託すの3レイヤー型 Web プラットフォーム。

## デモ URL

- 稼働中プロトタイプ： https://trust-design-navi.vercel.app/

---

## v5 → v6 の主な進化（ピボット含む）

### 1. VPC を v7.5 へ更新：5本の「底流テーマ」を統合

表メッセージはマイルドに保ちつつ、コンテンツ設計の判断軸として5つの底流テーマを採用。

1. 家族任せ・性別役割任せをやめる
2. 2040年問題（単身世帯 約4割化）への備え
3. COTEN型の構造理解（個人の悩み ↔ 社会構造）
4. 世代間負担の引き受け
5. 専門家と賢く繋がる実践者像

### 2. コアペルソナを再定義

> **「家族の枠に縛られず、自立期に主体的に備えたい40–50代」**

サブセグメント：
- A. 親サポート世代
- B. 単身／子なし世帯
- C. ケア負担を背負う／避けたい女性

### 3. 10テーマ → 6テーマへ統合

診断のフリクションを下げるため、診断テーマを整理統合した。

| 新テーマ | 統合元 |
|---|---|
| ①医療と判断力の備え | 旧2＋3＋7 |
| ②介護・住まい・見守り | 旧1＋5 |
| ③資産とお金 | 旧4 |
| ④家族以外の支援 | 旧6＋8 ＋新規要素 |
| ⑤死後の手続きと相続 | 旧9＋10 |
| ⑥デジタル資産・SNS・暗号資産 | 新規 |

### 4. クリプト託し戦略：段階的アプローチに整理

Phase 1 は教育＋テンプレ提供のみに留め、まず自分で実践して Pain を発見してから自前機能化を検討する仮説駆動の戦略を採用。秘密鍵・シードフレーズ管理はリスクが重いため、急がない判断。

### 5. Phase 1 タスク分解の確定

12タスクを Tier 1（必須）／Tier 2（高優先）／Tier 3（できれば）に分類。合計見積 約46–56時間。
推奨実行順序・依存関係を明文化。

## 差別化の刃

| | 一般的な終活サービス | TDN v7.5 |
|---|---|---|
| 顧客像 | 高齢者本人＋家族 | 自立期＋家族の枠を問わない |
| 家族観 | 家族あり前提 | 家族の有無を問わない |
| ジェンダー | 暗黙の女性負担 | ジェンダー視点で再設計 |
| 領域 | 相続・介護中心、紙ベース | デジタル/SNS/クリプト厚め、Web |
| 提供価値 | 個人課題の解決 | 個人課題＋社会構造への接続 |
| 専門家関係 | 専門家に丸投げ | 専門家と対等に繋がる |

## 現時点で動くもの

- ランディングページ（コンセプト・3レイヤー説明・診断 CTA）
- 6テーマ診断（リテラシーマップ表示＋優先テーマ提示）
- AI ナビゲーター（CHAT_SCENARIOS による対話的深掘り）
- 関係性マップ（家系図エディタ・PDF出力）
- Supabase 認証＋家系図クラウド保存／ロード

**技術スタック：** Vanilla JS ＋ HTML/CSS ＋ Supabase（Auth / Postgres / RLS） ＋ Vercel（CI/CD）。
ビルドステップを敢えて入れず、Vercel への直反映で軽量・高速に回している（Phase 1 段階）。
