## 【ブース展示】構想・内容説明（標準版）

```
Trust Design Navi（TDN）は、家族の枠に縛られず、自立期（40–50代）に主体的に「これからの安心」を備えるための Web プラットフォームです。

「家族あり・配偶者あり・子あり」を前提にしてきた既存の終活サービスでは取りこぼされてきた、単身世帯・子なし世帯・ジェンダーで偏ったケア負担といった現代的なペインに正面から向き合います。2040年に単身世帯が約4割になると言われる社会で、「家族任せ・性別役割任せをやめる」を底流テーマに、誰もが備えを自分でデザインできる状態を目指します。

【3レイヤー構造】
・学ぶ：6テーマ（医療と判断力／介護・住まい・見守り／資産とお金／家族以外の支援／死後の手続きと相続／デジタル資産・SNS・暗号資産）の構造解説コンテンツ
・決める：現在地診断＋優先テーマ提示／AIナビゲーターによる対話的深掘り／デジタル遺品・SNS死後対応・クリプト託しなど見落とし領域の専用モジュール
・託す：家族・友人・士業・地域・サービスを束ねる関係性マップ／安心デザインカード（家族・専門家共有用1枚PDF）

【技術スタック】
Vanilla JS ＋ HTML/CSS ／ Supabase（Auth・Postgres・RLS）／ Vercel（CI/CD）。Phase 1 はビルドレスでデプロイし、素早い検証サイクルを優先。Phase 2 以降で LLM 連携・実践者コミュニティ機能を予定。

【デモ URL】
https://trust-design-navi.vercel.app/

ブースでは、現在地診断 → リテラシーマップ → 関係性マップ作成までを実機で体験いただけます。「家族の有無に関わらず、自分でデザインする終活」をどう設計しているかを直接お見せします。
```
