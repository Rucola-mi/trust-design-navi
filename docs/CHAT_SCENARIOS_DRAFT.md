# Trust Design Navi v7.5 — CHAT_SCENARIOS 草稿（Task 3）

このドキュメントは、Phase 1 Task 3 の成果物。AIナビゲーターチャット（現状はモック）の対話シナリオを、新6テーマ用に書き直したもの。レビュー・調整後、`app.js` の `CHAT_SCENARIOS` オブジェクトに流し込む。

## 設計方針

v7.5マニフェスト準拠：

- **既婚前提・子あり前提の問いを避ける**：選択肢に「家族に頼れない／該当する人がいない」等の逃げ道を設ける
- **「家族／友人／専門家／自分自身」を多角化**：家族一択にならない選択肢構成
- **「専門家と賢く繋がる」視点**：士業・地域サービスへの認知を選択肢に含める
- **底流テーマは表面化させない**：スローガン化せず、問いかけの中に自然に混ぜる

各シナリオの構造：

```javascript
{
  intro: '...',      // 1行のオープニング
  steps: [
    { bot: '...', options: ['...', '...', '...', '...'] },  // 4択
    { bot: '...', options: ['...', '...', '...', '...'] },
    { bot: '...', options: ['...', '...', '...', '...'] }
  ]
}
```

3問 × 6テーマ = 18問／72選択肢。

## テーマ1：医療と判断力の備え

```javascript
1: {
  intro: '「医療と判断力の備え」について、最初に知るとよいことを一緒に整理しましょう。',
  steps: [
    {
      bot: 'もしも自分で治療方針を判断できない状態になった時、まず気になることはどれですか？',
      options: [
        '誰に代わって話してほしいか',
        'どんな治療を望むか（延命の是非など）',
        '自分の意思をどう伝え残すか',
        'まだイメージが湧かない'
      ]
    },
    {
      bot: '医療の意思決定を「誰に託すか」と考えた時、いま思い浮かぶ相手はどれに近いですか？',
      options: [
        '親族（配偶者・子・きょうだい・甥姪など）',
        '士業の専門家（弁護士・司法書士・行政書士など）',
        '知人・友人',
        '専業事業者（高齢者等終身サポート事業者・社会福祉協議会など）'
      ]
    },
    {
      bot: '「ACP（人生会議）」や「事前指示書」というしくみを、ご存じでしたか？',
      options: [
        '知っていて、書いたことがある',
        '名前は知っているが、まだ書いていない',
        '名前は聞いたことがある',
        '初めて知った'
      ]
    }
  ]
}
```

**設計意図**：Step 2 は「誰に託すか」の4カテゴリ（親族／士業／知人・友人／専業事業者）で問う。家族関係が薄いユーザーには「専業事業者」が実質の受け皿となる。テーマ4 Step 1 と対称構造。Step 3 は制度理解度を4段階で把握。

## テーマ4：家族以外の支援

```javascript
4: {
  intro: '「家族以外の支援」、選択肢を知るところから一緒に整理しましょう。',
  steps: [
    {
      bot: 'もし入院や施設入所で身元保証人が必要になった時、誰に頼むことをイメージしますか？',

        '士業の専門家（弁護士・司法書士・行政書士など）',
        '知人・友人',
        '専業事業者（高齢者等終身サポート事業者・社会福祉協議会など）'
      ]
    },
    {
      bot: '「任意後見契約」や「死後事務委任契約」というしくみを、ご存じですか？',
      options: [
        '知っていて、検討中または契約済み',
        '名前を聞いたことがある',
        '初めて聞いた',
        '内容が難しくてよく分からない'

      bot: '「高齢者等終身サポート事業者」の存在は、ご存じでしたか？国が2024年にガイドラインを示すなど、業界整備がいま進んでいる領域です。',
```

## レビュー観点

1. **選択肢の逃げ道**：各テーマのStep 2〜3で、単身・子なし・家族関係が薄いユーザーが違和感なく選べる選択肢が入ってるか？
2. **botの問いかけトーン**：押し付けがましくない？重すぎない？軽すぎない？
3. **テーマ4（家族以外の支援）**：Step 3の悪質業者への言及、これで適切？煽りすぎ？
4. **テーマ6（デジタル）**：暗号資産の質問、持ってない層にも配慮できてる？
5. **各テーマの差別化度**：テーマごとに明確に違う話をしてるか？重複感ないか？
